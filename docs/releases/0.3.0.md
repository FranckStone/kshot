# KShot 0.3.0

- 统一“识别与翻译”入口，同时提取文字、识别二维码并翻译；纯二维码保留原始内容，可直接复制或打开链接。
- 新增 DeepSeek 与 Ollama 翻译引擎，支持配置服务地址和模型，DeepSeek API Key 保存在系统钥匙串；保留 Apple 系统离线翻译。
- AI 译文边生成边显示，支持复制已生成文字、中途停止和重新翻译；连接中断时保留未完成内容并明确提示。
- 翻译窗口可直接切换引擎和模型、读取可用模型列表，也可输入模型名称；记住最近选择，多个窗口各自保留当前配置。
- 优化原文与译文双栏窗口，支持调整大小、编辑和独立复制；翻译保留原文换行、空行、缩进、列表编号和项目符号。
- 翻译设置新增默认目标语言和 Apple 离线翻译包下载、状态检查及系统语言管理入口。
- 改进语言自动检测，过滤网址、邮箱与编号干扰，参考附近语句判断短标签；也可手动指定原文语言。
- 当前发行采用 Apache 2.0 许可，保留 KShot 来源与第三方授权声明。

适用于 Apple Silicon 和 macOS 14 或更高版本；Apple 系统离线翻译需要 macOS 15 或更高版本。AI 翻译需先配置可用服务和模型。

现有用户可通过菜单栏“检查更新…”安装；也可下载 DMG 或 ZIP。安装包使用 Apple Development 证书签名，尚未完成 Apple 公证。
