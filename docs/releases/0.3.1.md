# KShot 0.3.1

- 优化 DeepSeek 和 Ollama 多行翻译速度：将正文合并为分块请求，每块最多 32 行或约 6 KB，减少逐行请求的重复等待。
- 保留原文换行、连续空行、缩进、列表编号和项目符号；二维码等受保护内容和无需翻译的行由程序原样保留。
- 分块翻译继续支持边生成边显示，包括当前行尚未生成完整时的正文；停止或连接中断时保留已显示的译文。
- 模型返回缺行、重复编号或无法解析的分块格式时，自动回退逐行翻译，避免译文错位或遗漏。

已通过全部 68 项自动化测试，覆盖分块请求、排版还原、流式显示、停止、中断和格式异常回退；请求数量测试验证 20 行短文本使用 1 次请求、70 行使用 3 次请求。

适用于 Apple Silicon 和 macOS 14 或更高版本；Apple 系统离线翻译需要 macOS 15+。AI 翻译需配置可用服务和模型。
